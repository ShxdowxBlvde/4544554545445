# Личный кабинет пользователя банка
## Описание:

Любой пользователь в любой момент может посмотреть номер своего банковского счета и историю своих операций.
Также есть функционал предназначенный для обработки, фильтрации и анализа банковских транзакций, а также для генерации валидных номеров карт.

## Новый функционал

Проект содержит модуль `generators.py`, внутри которого реализованы:
*   **`filter_by_currency`**: Фильтрует список транзакций по заданному коду валюты (например, `USD`, `RUB`). Устойчив к некорректным или неполным структурам данных
*   **`transaction_descriptions`**: Возвращает описание (`description`) для каждой транзакции. Если описание отсутствует, возвращает пустую строку
*   **`card_number_generator`**: Генерирует номера банковских карт в формате `XXXX XXXX XXXX XXXX` в заданном диапазоне с автоматическим дополнением нулями слева

## Инструкция по запуску тестов

1. Убедитесь, что у вас установлены все зависимости (включая `pytest`):
   ```
   poetry install
   ```
   *(Или `pip install -r requirements.txt`, если вы не используете Poetry)*

2. Запустите тесты из корневой директории проекта командой:
   ```
   pytest
   ```

3. Для получения более подробного отчета о прохождении тестов используйте флаг `-v`:
   ```
   pytest -v
   ```
